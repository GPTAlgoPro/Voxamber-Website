支持中心

遇到问题，或想分享一个新想法？从这里找到帮助。

通过 GitHub 联系开发者

支持入口由 GitHub Issues 提供，需要 GitHub 账户。提交的内容可能公开可见，请不要附上密码、个人隐私、未公开作品或完整设备日志。

使用你自己的 AI

先在维珀复制创作说明，再到你自己的 ChatGPT、Gemini、Grok、Claude、Qwen、GLM、Kimi 或 DeepSeek App 描述想法。第三方 AI 的账户、订阅和使用由你在对方服务中处理；维珀不收取或代管这些账户和 API 密钥。

导入代码与本机生成

将 Three-Live 兼容场景代码粘贴回来、从文件导入，或使用所安装版本提供的系统分享入口。分享扩展只在你确认后存入本机导入箱，不运行代码、不读取对话链接，也不会自动打开主 App。请打开维珀检查导入项，再点击生成。

代码报错或生成未完成

生成使用 Google Three-Live 官方原生 SDK，不是完整浏览器中的 Three.js。请按 App 创作说明使用支持的接口；若报错，可复制错误和你愿意提供的代码交给自己的 AI 修改。记录版本、设备、时间和步骤，检查作品库；看到进度不代表已保存成功。

保存、导出与 AR

生成并保存后可在作品库重新打开，编辑源码后重新生成会保存新版本。通过系统分享导出 GLB、USDZ 或场景源文件。外部保存与云同步由你选择的服务处理；AR 需要相机权限和设备支持。

导入范围与本机数据

原始导入内容最多 4 MiB，实际执行的场景代码最多 1 MiB，需为 UTF8 文本。导入和编译无需强制下载 AI 模型。请先导出需要保留的模型与源码；移除 App、系统备份和外部副本按各自系统规则管理。

测试版反馈

已获邀请的 TestFlight 测试者也可以通过 TestFlight 的“发送 Beta 版反馈”联系开发者。反馈和崩溃诊断由 Apple 按其平台规则处理。尚未公开提供下载或测试邀请链接。

反馈时提供这些信息即可

  • App 版本与构建号
  • 设备型号、iOS 版本
  • 操作步骤与预期结果
  • 实际出现的提示或大致时间
