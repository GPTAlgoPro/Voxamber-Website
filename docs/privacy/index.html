隐私政策

你的构想、作品与分享选择，由你掌握。

生效及更新日期：2026 年 11 月 5 日

1. 本政策适用范围

本政策适用于维珀（Voxamber）App 及本官网，由 Voxamber 开发者提供。当前 App 处于开发测试阶段；本页会随实际数据处理方式的变化更新。

2. 保留在设备中的内容

设计描述、作品参数、生成模型、草稿和本地运行记录保存在设备的 App 存储空间中。我们没有用于接收这些创作内容的自建云推理服务。App 不要求注册账户，不包含广告或第三方广告、统计分析 SDK。

3. 模型资源下载

首次安装或更新模型资源需要联网。模型素材包将通过 Apple 素材托管分发；开发版本也可能使用 Hugging Face 或 ModelScope 的公开资源。资源服务方会为传输和安全处理必要的网络连接信息，例如 IP 地址、资源请求与连接时间。模型下载不会把你的设计描述或作品作为下载内容上传。服务方的数据处理受其各自政策约束。

4. 相机与文件权限

相机仅在你选择系统 AR 预览等需要相机的功能时使用，并由系统请求权限。此用途不要求向我们上传相机画面。文件选择器仅让 App 访问你主动选择的资源；分享与导出由你决定目标位置。

5. 你主动分享的内容

你可以把作品导出到“文件”、云盘或其他应用。导出后的副本由你选择的服务及其隐私政策管理。如果你主动通过 GitHub Issues 或 TestFlight 提交反馈，相关平台会处理你提交的内容与账户信息；GitHub 问题可能公开，不要提交敏感资料。

6. 诊断、TestFlight 与系统服务

App 可在本机保存生成耗时等运行记录，便于查看与排查问题，不通过自建后台自动上传。Apple 可能依据你的系统设置、TestFlight 使用方式和 Apple 的政策收集或向开发者提供诊断及反馈。该平台处理与 App 内第三方统计 SDK 不同。

7. 保留、删除与备份

你可以删除作品、清理本机模型，或按照 iOS 方式移除 App。我们没有创作内容的远端账户或服务器副本供统一删除。系统备份、你已导出的副本和主动发送的反馈需要在相应系统或服务中管理。移除素材包与移除作品是不同操作。

8. 本官网

本网站使用 GitHub Pages 托管，没有广告、分析脚本、追踪像素或我们设置的追踪 Cookie。GitHub 为提供和保护托管服务可能处理访问日志等信息，具体依其隐私政策。语言页面直接通过链接切换，不依赖追踪存储。

9. 儿童与内容

本 App 是创作工具，没有面向儿童的资料收集流程。请只输入和分享你有权使用的内容；生成结果可能存在错误或不完整，使用、加工或公开发布前应自行检查。

10. 联系与更新

隐私疑问、数据管理问题或政策更新建议可通过支持页的 GitHub 联系入口提交。请先描述问题，不要在公开问题中发送个人隐私。若本政策发生实质变化，我们会更新本页日期，并按适用要求提供说明。
