隐私政策

你的构想、作品与分享选择，由你掌握。

生效及更新日期：2026 年 11 月 6 日

1. 本政策适用范围

本政策适用于维珀（Voxamber）App 及本官网，由 Voxamber 开发者提供。当前导入优先流程为：用户在自己的 AI 服务中取得场景代码，主动导入后在手机生成、预览、编辑和导出。App 处于开发测试阶段；本页会随实际数据处理方式更新。

2. 保留在设备中的内容

原始导入内容、场景源码、生成模型、草稿、作品版本和本地运行记录保存在设备中。系统分享仅把你确认的文本或文件存入本机导入箱。维珀不把这些代码或作品上传到我们的服务器；App 不要求注册维珀账户，不包含广告或第三方广告、统计分析 SDK。

3. 你选择的第三方 AI

维珀不强制下载 AI 模型，不收取或代管第三方 AI 账户、密码或 API 密钥，也不会替你向 AI 服务发起对话。你在第三方 App 中提交描述或代码、使用账户和付费，均由你直接与该服务进行，受其设置、条款和隐私政策约束；这不属于维珀的本机编译过程。

4. 相机、文件与系统分享

相机只在你选择系统 AR 预览等功能时由系统请求使用，不要求向我们上传画面。文件导入只读取你主动选择的内容；从其他 App 分享时，需要你确认存入，维珀不会抓取 AI 对话链接。你决定模型和源码的导出位置，文件或云盘服务的数据处理遵循其自身政策。

5. 你主动发送的内容

你可以把场景代码带回自己的 AI 修改，或把模型与源码导出到“文件”、云盘或其他应用；接收服务将依据其政策处理这些副本。主动通过 GitHub Issues 或 TestFlight 提交反馈时，平台会处理你提交的内容和账户信息；GitHub 问题可能公开，请勿提交敏感资料。

6. 诊断、TestFlight 与系统服务

App 可在本机保存编译耗时等运行记录，便于排查问题，不通过自建后台自动上传。Apple 可能依据你的系统设置、TestFlight 使用方式和 Apple 政策处理诊断及反馈。这些平台行为与维珀内嵌第三方统计 SDK 不同。

7. 保留、数据管理与备份

导入原文、源码、草稿及保存版本在本机保留；标记分享项已接收不会删除作品。请先导出需要保留的内容，再使用所安装版本提供的数据管理功能或按 iOS 方式移除 App。我们没有这些创作内容的远端账户或服务器副本。系统备份、外部导出副本、AI 对话及主动发送的反馈需在相应服务中分别管理。

8. 本官网

本网站使用 GitHub Pages 托管，没有广告、分析脚本、追踪像素或我们设置的追踪 Cookie。GitHub 为提供和保护托管服务可能处理访问日志等信息，具体依其隐私政策。语言页面直接通过链接切换，不依赖追踪存储。

9. 儿童与内容

本 App 是创作工具，没有面向儿童的资料收集流程。请只导入、执行和分享你有权使用的场景代码。代码可能不兼容，生成结果可能错误或不完整；使用、加工或公开发布前应自行检查。

10. 联系与更新

隐私疑问、数据管理问题或政策更新建议可通过支持页的 GitHub 联系入口提交。请先描述问题，不要在公开问题中发送个人隐私。若本政策发生实质变化，我们会更新本页日期，并按适用要求提供说明。
