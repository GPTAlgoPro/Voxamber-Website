From a thought to a creation.

01

Create code with your AI

Describe your idea in your own AI App. Use the instructions from Voxamber to request Three-Live-compatible scene code. The subject is yours.

02

Import and generate on iPhone

Paste code, choose a file, or save it to Voxamber through system sharing. Review the source, then generate and preview it with the official native Google Three-Live SDK.

03

Edit and take your work further

Edit scene code and regenerate to save a new revision. Share GLB, USDZ, or the scene source file, or open system AR preview.

Code must use the supported Three-Live APIs. Features and generation depend on your device, OS, scene complexity, and installed version. Inspect the actual result.

Create on device.
Share by choice.

Scene code and creations in Voxamber stay on your device and are not uploaded to our servers. No AI model download, third-party AI account, or API key is required inside the App.
