Support center

Need a hand, or have an idea to share? Start here.

Contact the developer on GitHub

Support is provided through GitHub Issues and requires a GitHub account. Submissions may be public. Do not attach passwords, personal information, unpublished work, or complete device logs.

Use your own AI

Copy the authoring instructions from Voxamber, then describe your idea in your own ChatGPT, Gemini, Grok, Claude, Qwen, GLM, Kimi, or DeepSeek App. You manage that service, account, subscription, and use directly. Voxamber does not collect or manage those accounts or API keys.

Import code and generate locally

Paste Three-Live-compatible scene code, import a file, or use system sharing when provided by your installed version. The Share Extension saves to the local inbox only after your confirmation. It does not execute code, fetch conversation links, or open the main App automatically. Open Voxamber, review the item, and choose Generate.

Code errors or incomplete generation

Generation uses the official native Google Three-Live SDK, rather than a full browser Three.js environment. Follow the supported APIs in the App instructions. You can copy an error and code you choose to share back to your own AI for revision. Record the version, device, time, and steps, and check Creations: visible progress alone does not mean a successful save.

Saving, exporting, and AR

Reopen saved creations, edit their source, and regenerate to save a new revision. Export GLB, USDZ, or the scene source file through system sharing. External storage and syncing are handled by your selected service. AR requires camera permission and device support.

Import limits and local data

Original imports are limited to 4 MiB and executable scene source to 1 MiB, in UTF8 text. Importing and compiling do not require an AI model download. Export any model and source you need to keep. App removal, system backups, and external copies follow the relevant system or service rules.

Beta feedback

Invited TestFlight testers can also use Send Beta Feedback in TestFlight. Apple processes feedback and crash diagnostics under its platform rules. No public download or testing-invitation link is currently offered here.

Useful details for a report

  • App version and build number
  • Device model and iOS version
  • Steps and expected result
  • The message you saw or approximate time
