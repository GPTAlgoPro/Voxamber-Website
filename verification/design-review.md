# Design and verification record

Date: 2026-11-05

The built-in image generator created a complete three-section website concept from the existing Voxamber App icon. A second built-in edit removed only the icon background for the website's abstract brand artwork. Both the concept and browser screenshots were inspected with `view_image`.

Verified comparison points:

1. Midnight navy background, pale text, cyan/jade primary control, and violet glass artwork match the concept's direction.
2. The hero keeps its three-line title, open two-column structure, explanatory text, workflow action, real support action, and honest development status.
3. The exact App icon is used as the brand mark; the larger transparent sculpture is explicitly identified as an abstract illustration, never an App output sample.
4. Workflow content uses three open columns with hairline dividers rather than nested cards, and reflows into clear rows on mobile.
5. The privacy band, footer hierarchy, system typography, readable legal text, and language navigation retain the same visual system.
6. A mobile orphan-line issue in the workflow heading and a transparent-image overflow on desktop were corrected.

Intentional additions: a compatibility/generation-quality paragraph required by the actual product state, and separate bilingual support/privacy documents. The concept's branding illustration was extracted to a transparent asset to avoid a square image background. No fake metrics, release download link, testimonials, form submission, or tracking scripts were added.

Local Browser/IAB checks: all six pages at 390x844 and 1440x1000, one main heading each, no horizontal overflow, all image assets loaded. Header language links preserve the corresponding support/privacy route. Support contact points to the public GitHub Issues form and states that an account is required and submissions can be public. The site makes no guarantee of App Store acceptance.
